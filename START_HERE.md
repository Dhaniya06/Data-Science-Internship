# Data Science Beginner Project Pack

This pack contains four separate beginner projects. Each project folder is designed to be uploaded to GitHub as its own repository.

## Projects
1. Sales Data Analysis and Visualization
2. Student Performance Analysis
3. Iris Flower Classification using Machine Learning
4. House Price Prediction using Regression

## Getting started
- Open one project folder.
- Read its README.md.
- Create a virtual environment if desired.
- Install dependencies with `pip install -r requirements.txt`.
- Run the Python script and inspect the generated `outputs/`.
- Complete `REPORT_TEMPLATE.md` using results from your own run.

## GitHub upload
Create a separate repository for each folder, then from inside that folder run:
```bash
git init
git add .
git commit -m "Add beginner data science project"
git branch -M main
git remote add origin https://github.com/YOUR-USERNAME/REPOSITORY-NAME.git
git push -u origin main
```
Replace the URL with your own repository URL.
