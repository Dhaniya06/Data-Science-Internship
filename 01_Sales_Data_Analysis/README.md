# Sales Data Analysis and Visualization

## Objective
Explore sample retail orders and summarize sales trends, product-category revenue, and regional performance.

## Tools
Python, Pandas, Matplotlib, Seaborn.

## Run locally
1. Install Python 3.10+.
2. Install dependencies: `pip install -r requirements.txt`
3. Run: `python sales_analysis.py`

The script reads `data/sales_data.csv` and writes charts and a monthly summary to `outputs/`.

## Dataset
`data/sales_data.csv` is a small, synthetic practice dataset created for this project. It is not real company data.

## Questions explored
- How does revenue change month to month?
- Which product category contributes the most revenue?
- Which region generates the highest revenue?
