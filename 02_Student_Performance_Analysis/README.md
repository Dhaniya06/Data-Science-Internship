# Student Performance Analysis

## Objective
Explore a synthetic student dataset and investigate possible relationships among study time, attendance, previous score, and exam score.

## Tools
Python, Pandas, Matplotlib, Seaborn.

## Run
`pip install -r requirements.txt`  
`python student_analysis.py`

## Dataset
`data/student_performance.csv` contains synthetic practice data, not real student records.

## Analysis
- Summary statistics for numeric columns
- Correlation matrix
- Scatter plot of study hours versus exam score
- Exam score distribution
- Average score by class level

## Responsible interpretation
Correlation does not prove causation. Do not use this small synthetic dataset to make decisions about real students.
