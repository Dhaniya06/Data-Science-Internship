# Iris Flower Classification using Machine Learning

## Objective
Build a beginner-friendly classifier that predicts Iris species from sepal and petal measurements.

## Tools
Python, Pandas, scikit-learn, Matplotlib.

## Run
`pip install -r requirements.txt`  
`python iris_classification.py`

## Dataset
The well-known Iris dataset is loaded from scikit-learn, so no manual dataset download is needed.

## Workflow
1. Load and inspect data.
2. Split into training and test sets.
3. Standardize features and train Logistic Regression.
4. Evaluate with accuracy, precision/recall report, and a confusion matrix.

## Important
The printed test score is based on one split and is not a guarantee of performance on every dataset.
